Лист бумажного расчёта

Учебная задача, не реальное судовождение. Один комплект для двух наблюдений. Источник чисел — выбранное условие, не игра. Впишите его название и дату, чтобы не смешать учебную пару, исторический разбор и новую задачу.

Условие / название задачи: ________________________________
Дата наблюдений по условию: ________________________________
Выполняет / дата расчёта: ________________________________

Для первого прохода используйте полный разбор, затем заполните новый экземпляр по самостоятельной задаче. Пособие и оригиналы таблиц можно держать открытыми; ключ самостоятельной задачи — отдельно.

Область этого листа: Солнце, нижний край; северные широта и склонение; меньший часовой угол < 90°; q между 0° и 90°; Hc выше 0° и не выше 70°; для азимута δ < Gr.δ, отсчёт от юга. Это бланк разобранной ветви, не универсальный алгоритм для всех полушарий. Если условие ветви не выполнено, остановитесь и отметьте его, а не применяйте напечатанную сумму автоматически.

Как заполнять клетки: в каждом поле сохраняйте единицы. Например, для первого наблюдения разобранной пары 3 сентября: адрес F VIII — PDF 98; строки 38° / 40°; глаз 5 / 6 м; четыре клетки в порядке «нижняя строка слева/справа, верхняя слева/справа» — +10,9′ / +10,5′; +11,0′ / +10,6′. Доля глаза — (5,5 − 5)/(6 − 5) = 0,5, поправки строк — +10,7′ / +10,8′. Это пример формата, не числа новой задачи.

Ho/Hc на листе можно записывать до 0,01′ для чтения. Для последующих вычислений сохраняйте выражение с долей или значение в памяти калькулятора; округлённую запись обратно не подставляйте. Рабочие a и Zn округляются один раз перед построением. Если места мало, продолжите на обороте с названием поля и номером наблюдения — не стирайте исходные клетки ради ответа.
